# My Portfolio

Personal portfolio website built with React and Tailwind CSS.

This website showcases my profile, skills, projects, and ways to get in touch with me.

## 🚀 Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- React Icons

## ✨ Features

- Responsive design
- Dark developer-themed UI
- Hero section
- About Me section
- Skills & technologies
- Project showcase
- Contact information
- Mobile responsive navigation
